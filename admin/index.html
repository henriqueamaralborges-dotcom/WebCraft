Banco de Dados em Nuvem (Firebase Cloud Firestore)

Verificando conexão...

Conecte seu banco de dados Firebase para que todos os clientes que se cadastrarem no site apareçam instantaneamente no seu painel em tempo real, mesmo em computadores ou celulares diferentes.

Você pode colar o código inteiro ou preencher os campos detalhados abaixo.

Como criar seu banco gratuito no Firebase em 3 minutos:

  1. Acesse console.firebase.google.com com sua conta Google e clique em Adicionar Projeto;
  2. No menu lateral, vá em Build ➔ Firestore Database e clique em Criar Banco de Dados (escolha o modo de teste ou configure as regras para leitura/escrita);
  3. Vá nas Configurações do Projeto ⚙️ (ícone de engrenagem) ➔ role até Seus aplicativos ➔ clique no ícone Web </>;
  4. Copie o bloco firebaseConfig e cole no campo acima! Pronto, seu site e painel estarão conectados na nuvem com dados em tempo real.
